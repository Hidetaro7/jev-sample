# jev-sample

TypeSafe AI の判定モデル「Jev」を Node.js で試す、小さな作例集です。

Jev は文章を書くAIではなく、**判定だけを返すAI**です。渡した材料について「はい／いいえの確率」「選択肢のどれか」「何点か」を、決まった形のデータで返します。

## 準備

Node.js 20 以上が必要です。

1. 部品を入れる

   ```
   npm install
   ```

2. [TypeSafe のコンソール](https://console.typesafe.ai/home)で API キーを発行する

3. このフォルダに `.env` という名前のファイルを作り、次の1行を書く

   ```
   TYPESAFE_API_KEY=発行したキー
   ```

`.env` は `.gitignore` に入っているので、GitHub には上がりません。

## 作例

| コマンド | ファイル | 内容 |
|---|---|---|
| `npm start` | `index.js` | お問い合わせ文を仕分けて、結果をターミナルに表示する |
| `npm run web` | `server.js` | 同じ仕分けを、ブラウザの入力欄から試す |
| `npm run live` | `live.js` | 文章を打っている途中で、トンマナ（文体のルール）に合っているかを採点する |

`npm run web` と `npm run live` は、起動後にブラウザで http://localhost:3000 を開きます。止めるときはターミナルで Ctrl + C を押します。

## 質問の型

Jev への質問は3種類です。

| 型 | 聞くこと | 返ってくるもの |
|---|---|---|
| `noul` | はい／いいえ | 0〜1 の確率 |
| `choice` | 選択肢から1つ | 選ばれた選択肢と、自信の度合い |
| `score` | 段階評価 | 点数 |

## 質問を書くコツ

- **1つの質問で1つのことだけ聞く。** 「ロゴかWebか」を1問で聞くより、「ロゴがほしいか」「Webがほしいか」の2問に分けたほうが、数字がはっきり出ます。
- **選択肢には説明をつける。** 名前だけより、何を指すかを一言添えたほうが迷いません。
- **「その他」の逃げ道を用意する。** ないと、無理やりどれかに当てはめます。
- **自信が低いときは人に回す。** 数字で返るので、「70%以下なら人が確認する」のようなルールを自分で書けます。
- **「すべてOKか」をまとめて聞かない。** 項目ごとに聞いて、結果を自分のルールでまとめます。

## うまく動かないとき

**`401 Cannot authenticate` が出る**

`.env` のキーが正しいのに出る場合は、ターミナルが別のキーを覚えています。次で確認できます。

```
echo $TYPESAFE_API_KEY
```

何か表示されたら、そちらが `.env` より優先されています。`unset TYPESAFE_API_KEY` を実行してから、もう一度起動してください。毎回出る場合は、`~/.zshrc` などに書かれた `export TYPESAFE_API_KEY=…` の行を消し、ターミナル（エディタ内のターミナルならエディタごと）を完全に終了して開き直します。

**キーを変えたのに反映されない**

`npm run web` と `npm run live` は、起動したときに一度だけ `.env` を読みます。Ctrl + C で止めて、起動し直してください。
